# Homebrew Tap

Homebrew formulae for [golit](https://github.com/zeroedin/golit).

## Install

```sh
brew tap zeroedin/golit
brew install golit
```

## Available Formulae

| Formula | Description                                                                  |
| ------- | ---------------------------------------------------------------------------- |
| `golit` | Lit SSR in pure Go — server-side render Lit web components into Declarative Shadow DOM |
